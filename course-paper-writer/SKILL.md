# 课程论文写作流程

适用于：给定题目或选题清单、有明确格式与字数要求、要求提交 Word 文档的课程论文。

**这个 Skill 的产出物是 .docx 文件，不是一段文字。** 所有工作围绕三件事：约束不漏、出处可查、排版正确。

---

## 0. 六条铁律

1. **每个论断可核验。** 事实有出处，数据有统计范围，引文有版本。答不出"出自哪里"的句子就是风险句。
2. **不造词。** 术语用教材原话、标准原文、权威文献既有概念。自创的只能是分析框架的命名或比喻，且首次出现要一句话交代。
3. **案例要站得住。** 优先官方文件、监管公告、司法文书、标准原文、权威调查报告。争议未决的个案、网传名人名言一律不用。
4. **先算后写。** 字数配额、页数配额在动笔前分好，不要写完再删。
5. **反模板。** 各章颗粒度必须不同，禁止"三章各三节"；结语是散文不是清单。
6. **交付前自问**：如果老师逐句问"这句凭什么"，能不能当场答上来。

## 1. 读要求文件，填硬约束表

不要开口问用户要字数要求——要求就在文件里。

| 格式 | 工具 |
|---|---|
| `.docx` | `python -c` + `python-docx` 读段落与表格 |
| `.doc`（文件头 `D0CF11E0`） | `python scripts/extract_doc.py 要求.doc 要求.txt` |
| `.pdf` | `python scripts/extract_pdf.py 要求.pdf 要求.txt` |

两个提取器都是纯标准库实现，不依赖 LibreOffice。扫描件无文本层，提取为空就请用户贴文字，**不要硬猜**。

抄下这张表再动笔：

```
题目：        □给定 □自拟
字数：        ____ ～ ____ ，是否含摘要/参考文献：____
摘要：        ____ 字；关键词：____ 个
页数：        ____ 页
正文：        字体____ 字号____ 行距____（固定值/倍数）
标题层级：    ____ 级；各级字体字号（一级/二级/三级分别是什么）
文献：        不少于____ 篇；近____ 年占比≥____%；格式____（GB/T 7714 / IEEE / APA）
必备要件：    □引言 □正文 □结语 □参考文献 □致谢 □附录
内容要求：    ____（如"至少2个真实案例""须用××理论框架"）
评分权重：    ____
提交：        截止____ 邮箱____ 命名规则____
```

**评分权重决定力气分配。** 例如"问题有争议性 30%、框架运用 25%、案例翔实 20%、方案分层 15%、格式 10%"——这条信息比字数更重要，它告诉你哪一项值得花时间。

## 2. 题目 → 问题链

题目是词组，不能直接当提纲。要拆成能回答的问题：

| 题目成分 | 必须回答 |
|---|---|
| "为什么……" | 因果与机制，不是"是什么" |
| "……的困境/冲突" | 冲突双方的正当性各是什么 |
| "如何……/路径" | 可操作的方案，且分层 |
| "……研究/探析" | 一个可证伪的判断 |

**"伦理困境"的判定标准**：必须存在两个都站得住的义务相互冲突，且现有规范无法同时满足。若一方明显违规，那是**失范**，不是困境——遇到这种情况要主动告诉用户换题或换案例，不要硬写。

---

## 3. 联网取证

详见 `references/evidence-protocol.md`。三条要点：

- **源分三档**：A 档原始规范/标准/官方调查/权威教材，B 档同行评议文献，C 档权威媒体。结论靠 A 和 B，事实可以靠 C。
- **边搜边填记录表**，填满即等于写完：`我要说的那句话 | 依据（原文/数据） | 出处（作者、篇名、刊名、年、卷期、页） | 链接`。
- **查不到就标"待定"**，绝不编造。宁可在交付时列一张"待核对清单"，也不要塞一句假引用。

文献数量纪律：条数 = 要求下限 + 20%；近 N 年占比要留出余量，不要卡着线写。

## 4. 结构设计

通用骨架（按需裁剪）：

```
题目 → 摘要（问题—方法—结论）→ 关键词
一、引言        背景 → 已有讨论的不足 → 本文做什么
二、理论/框架    把分析工具讲清楚，并说明为何适用
三、案例/材料一  事实 → 冲突点 → 用框架切开
四、案例/材料二  与案例一对照
五、根源归因    为什么反复出现
六、方案        分层给抓手
七、结语        散文 2~3 段，回扣问题 → 提炼判断 → 一句收束
参考文献
```

**反模板三条**：
1. 各章颗粒度不同（可以是 3 / 0 / 4 / 0，有章分小节，有章连贯论述）。
2. 每章留一处自我设限：承认反例、划出适用边界。
3. 结论分层：按**单一标准**分成 2~4 层，不要一刀切"都对/都错"。

## 5. 遣词：如何避免 AI 味

这是最容易丢分的地方。一份读起来像 AI 写的论文，即使论证正确也会被判低分。

### 必须删掉的句式

| 病症 | 例子 | 处理 |
|---|---|---|
| 引言末尾三连问 | "本文要回答的是：A 是什么，B 为什么，C 在什么条件下……" | 删掉，改成陈述句或直接给案例 |
| 摘要末句表态 | "据此，本文主张……" | 删掉，改成研究结论的陈述 |
| 每段都配总结句 | "由此可见，……具有重要意义。" | **写不出好总结就别写**，让事实自己收尾 |
| 三段式排比 | "一是……二是……三是……" | 改成有详略的连贯论述 |
| 空话开头 | "随着科技的发展""众所周知" | 直接删 |
| 万能转折 | "综上所述""综合来看""笔者认为" | 换成实词：恰恰相反、正因如此、根子不在……而在…… |

### 必须避免的词

以下词是典型的"AI 论文腔"，人类写作很少用：

> 维度、抓手、赋能、闭环、范式、张力、勾连、建构、口径、边界、压缩、吸收

需要表达这些概念时，换成具体说法：
- "口径" → 写清"按什么统计"
- "边界" → 写"标准下限以上""两者的区别"
- "维度" → 写"从……看""这一方面"
- "抓手" → 写"具体动作"

### 正面要求

- 以判断句推进："××不是××，而是××。"
- 专业名词必须出现型号、参数、标准号、失效模式。判据：把专业名词全删掉文章还成立，说明你没写专业内容。
- 标题里不用问号、感叹号。
- 引号分三层：术语引号、引文引号（后跟上标序号）、强调引号。一页超过三处强调引号就显轻浮。

## 6. 生成 DOCX

详见 `references/docx-formatting.md`。四个必设项，缺一个就出错：

```python
# 1. 中文字体必须同时设 eastAsia，否则 Word 用西文字体渲染汉字
for a in ("w:ascii", "w:hAnsi", "w:eastAsia", "w:cs"):
    rFonts.set(qn(a), "宋体")

# 2. 行距有两种，别弄混
pf.line_spacing = Pt(20); pf.line_spacing_rule = WD_LINE_SPACING.EXACTLY  # 固定值
pf.line_spacing = 1.5                                                      # 倍数

# 3. 首行缩进"2 字符" = 2 × 正文字号（小四 12pt → 24pt）
pf.first_line_indent = Pt(24)

# 4. 标题层级全文必须一致
```

**上标引用用占位符**：正文写 `⟦n⟧`，渲染时切成上标 run 输出 `[n]`。写作与排版解耦，改序号只改占位符。

**序号必须按正文首次出现顺序编号**，并在生成后与参考文献表交叉核对一次（详见 pitfalls 第 4 条）。

## 7. 自检与交付

```bash
python scripts/check_paper.py 论文.docx --min 3500 --max 5000
```

分区报告字数：摘要 / 关键词 / 正文段落 / 小标题 / 参考文献。**只报一个数会误导**——上标序号算不算、小标题算不算，差两百字很常见。字数必须报三档：含标题、不含标题、不含标点。

判定线：

| 指标 | 合格 | 处理 |
|---|---|---|
| 字数 | 落在区间内，距上限 ≥ 30 字 | 超了删，差得多补论证不补废话 |
| 摘要 | 严格落在要求区间（含标点和不含标点都要满足） | 超一个字都不行 |
| 直接引文占比 | ≤ 17% | 长引文改间接引述 |
| 引用序号 | 1..N 连续，与文献表一一对应 | 加引文后整篇重排 |
| 字体字号行距 | 逐项一致，eastAsia 已设 | 抽查首段、正文段、文献段 |

交付时必须主动交代三件事：

1. **文件状态**：文件名、字数（三档）、估算页数、文献条数、近 N 年占比。
2. **待核对项**：推测信息逐条列出（译者、版次、期号、页码、学院名、学号），标"请核对"。
3. **修改建议**：仍显机械的段落、可再压的地方、答辩可能被追问的点。

## 附：本 Skill 的边界

- 只做**学术写作流程**，不做代写论文投稿、不伪造数据、不生成虚假引用。
- 查不到出处一律标"待定"，**不用看似合理的假引用填充**。这是本 Skill 的硬约束。
- 涉及具体学科判断（如某标准的适用性）时，以用户提供的教材与标准原文为准，不作超出文本的推断。
